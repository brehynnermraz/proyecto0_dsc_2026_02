# Modelos de servicio

Los tres modelos clásicos son IaaS, PaaS y SaaS, y se diferencian por cuánta
       responsabilidad asume el proveedor.

- IaaS: máquinas, redes y almacenamiento virtualizados.

- PaaS: una plataforma para desplegar aplicaciones sin gestionar el sistema operativo.

- SaaS: software listo para usar a través del navegador.

## Responsabilidad compartida

La seguridad se reparte entre proveedor y cliente según el modelo elegido.
